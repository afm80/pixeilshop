# نماذج TFLite (اختيارية)

ضع هنا ملفات النماذج المحلية لتفعيل تحويل الأنمي/الكرتون بالذكاء الاصطناعي:

- `animeganv2.tflite`  ← AnimeGANv2 (دخل NHWC، float32)
- `cartoongan.tflite`  ← CartoonGAN

إذا لم تكن الملفات موجودة يستخدم التطبيق تلقائياً فلتر كرتوني/كوميك محلي مكتوب بـ Dart،
فتبقى الميزة تعمل بدون أي نموذج.
الخدمة تقرأ أبعاد الدخل من النموذج نفسه، وتكتشف مجال القيم ([-1,1] أو [0,1] أو [0,255]) تلقائياً.
