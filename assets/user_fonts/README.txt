ضع هنا خطوطك (ttf / otf).
- كل مجلد فرعي = تصنيف في شاشة الخطوط (مثال: assets/user_fonts/ديواني وكوفي/xxx.ttf).
- ملفات خارج أي مجلد تُصنَّف تلقائياً حسب اسمها ووزنها (كوفي، نسخ، رقعة، إعلانية...) والباقي «أخرى»، وتُقسَّم صفحات من 40 خطاً.
- الخط الذي ليس فيه حروف عربية يُعتبر إنجليزياً تلقائياً.
- يقرأ البناء (GitHub Actions) الأسماء والتصنيفات تلقائياً عبر tool/scan_fonts.py.
